# Holt Skinner's Portfolio

Welcome to my personal website/portfolio!

Built with [Zensical](https://zensical.org/) and deployed on GitHub Pages.

## 🚀 Development

1.  **Install dependencies**:
    ```bash
    uv sync
    ```

2.  **Live Preview**:
    ```bash
    uv run zensical serve
    ```

3.  **Build**:
    ```bash
    uv run zensical build
    ```

## 🌐 Deployment

The site is automatically built and deployed to [holtskinner.com](https://www.holtskinner.com/) via GitHub Actions (or manual upload to the `gh-pages` branch).
